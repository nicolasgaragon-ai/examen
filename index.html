1. Derivadas con a y b

(c)′ = 0   (xⁿ)′ = n xⁿ⁻¹   (c·a)′ = c·a′   (a ± b)′ = a′ ± b′

Producto: (a·b)′ = a′b + a b′

Cociente: ({a|b})′ = {a′b − a b′|b²}

El signo − del cociente afecta a TODO el producto: −(a·b′). Pon paréntesis.

Cadena: [f(u)]′ = f′(u)·u′ (derivo de afuera hacia adentro y multiplico cada capa).

Ejemplo: (3x² + 1)⁵ → 5(3x² + 1)⁴·6x

3. Recta tangente y normal

① m = f′(x₀)   ② Tangente: y − y₀ = m(x − x₀)

③ Normal: y − y₀ = −{1|m}(x − x₀)   Si m = 0, la normal es la recta vertical x = x₀.

Siempre comprueba que el punto cumple la curva.

4. Derivación implícita (Problema 2)

Cada vez que derivo algo con y, multiplico por y′.

(y²)′ = 2y·y′   (sen 2y)′ = 2cos 2y·y′   (x·y)′ = y + x·y′ (es un producto)

Pasos: ① verifico el punto sustituyendo ② derivo los dos lados ③ junto los y′ ④ factorizo y′ ⑤ despejo ⑥ evalúo m en el punto ⑦ tangente y normal.

Ejemplo: x y + y² = 6 en (1, 2) → y + x y′ + 2y y′ = 0 → y′ = {−y|x + 2y} = −{2|5}

5. Tangente que toca otra vez (Problema 1)

① m = f′(x₀) ② L: y = y₀ + m(x − x₀) ③ calculo f(x) − L(x) ④ lo factorizo: tiene raíz doble en x₀

Si sale otra raíz doble en x = b, la recta también es tangente ahí: punto (b, L(b)).

Comprueba que f′(b) = m. Para "demuestre", escribe la factorización completa.

Ejemplo: f(x) − L(x) = x²(x − 2)² → raíces dobles 0 y 2.

6. Razones relacionadas (Problema 4)

① dibujo y nombro (todo depende de t) ② fórmula ③ derivo respecto a t ④ sustituyo después de derivar ⑤ despejo, unidades y signo (si baja, es negativo).

  • Pitágoras: x² + y² = L² → x·x′ + y·y′ = 0 → y′ = −{x·x′|y}
  • Área del triángulo: A = {xy|2} → A′ = {x′y + x y′|2}
  • Círculo: A = πr² → A′ = 2πr·r′   Esfera: V = {4|3}πr³ → V′ = 4πr²·r′
  • Rectángulo: A = l·w → A′ = l′w + l w′
  • Sombra o poste: triángulos semejantes, igualo razones y derivo.

Error clásico: sustituir los números antes de derivar. Todo se vuelve constante y sale 0.

7. Trazado de curvas (Problema 3)

① Dominio: denominador ≠ 0   ② Asíntotas verticales: denominador = 0 con numerador ≠ 0; límites laterales ±∞

③ Asíntota horizontal (grados): arriba menor → y = 0 | iguales → cociente de coeficientes líderes | arriba mayor → NO hay (si es 1 más, hay oblicua: divide).

④ f′: puntos críticos (f′ = 0), tabla de signos. + sube, − baja. Cambio + a − = máximo local. − a + = mínimo local.

⑤ Rango: rama por rama, con extremos y asíntotas. ⑥ Bosquejo: asíntotas punteadas, puntos clave.

Tipo examen: {x³|x² − x − 2} tiene denominador (x − 2)(x + 1) → AV en x = 2 y x = −1; grado 3 > 2, sin AH; al dividir sale oblicua y = x + 1.

9. Cambio de variable (u, du)

① u = lo de adentro de una raíz, paréntesis, exponente de e, argumento de sen o cos, o el denominador; su derivada debe aparecer afuera.

② du = u′ dx; despejo dx o el pedazo que sobra (si falta una constante, divido). ③ reescribo todo en u. ④ integro y regreso a x.

Ejemplo: ∫ {sen x|√(9 + cos² x)} dx → u = cos x, du = −sen x dx → −∫ {du|√(9 + u²)} = −ln|u + √(9 + u²)| + C

Ejemplo: ∫ {x|x² + 1} dx → u = x² + 1, du = 2x dx → {1|2} ln(x² + 1) + C

Olvidar la constante de du (el {1|2}) y dejar x mezcladas con u son los errores más comunes.

10. Integración por partes

∫ u dv = u·v − ∫ v du

LIATE: elijo u en este orden: Logarítmica, Inversa trig, Algebraica, Trigonométrica, Exponencial. dv es lo demás (debo saber integrarlo).

Ejemplo: ∫ x eˣ dx → u = x, dv = eˣ dx → du = dx, v = eˣ → x eˣ − eˣ + C

Tipo examen: ∫ x arcsen x dx → u = arcsen x, du = {dx|√(1 − x²)}, dv = x dx, v = {x²|2}. Queda una ∫ {x²|√(1 − x²)} dx: se resuelve con x = sen θ.

Tipo examen: ∫ x cos(ln x) dx → t = ln x (x = eᵗ, dx = eᵗ dt) → ∫ e²ᵗ cos t dt: partes dos veces; sale la misma integral y se despeja (integral cíclica).

Útil: ∫ e²ᵗ cos t dt = {e²ᵗ(2 cos t + sen t)|5} + C

11. Fracciones parciales

① Si el grado de arriba ≥ el de abajo, divido primero. ② Factorizo el denominador. ③ Propongo:

  • Factor lineal (x − r): {A|x − r}
  • Lineal repetido (x − r)²: {A|x − r} + {B|(x − r)²}
  • Cuadrático irreducible: {Ax + B|x² + bx + c}

Tipo examen: {1|x(x + 1)²(x² + x + 1)} = {A|x} + {B|x + 1} + {C|(x + 1)²} + {Dx + E|x² + x + 1}

④ Multiplico por el denominador, evalúo en las raíces y comparo coeficientes. ⑤ Integro: ∫ {dx|x − r} = ln|x − r|; ∫ {dx|(x + 1)²} = −{1|x + 1}; el cuadrático se integra completando cuadrado (arctan).

14. Errores comunes (lo que más quita puntos)
  • Sin procedimiento escrito vale cero: escribe u, du, cada paso y la conclusión.
  • Olvidar + C, o el signo − al derivar cos, cot y csc.
  • Cociente: no repartir el signo menos. (a/b)′ ≠ a′/b′; (ab)′ ≠ a′b′.
  • Cadena: olvidar el último factor (la derivada de lo de adentro).
  • Implícita: olvidar y′ o tratar x·y como si y fuera constante.
  • Razones relacionadas: sustituir antes de derivar; olvidar el signo.
  • Intervalos: paréntesis para < y >, corchetes para ≤ y ≥; el infinito siempre con paréntesis.
  • Integrales: no regresar a x; no dividir entre la constante de du.
